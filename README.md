# TYPE CHECK — 完全静的CAPTCHAデモ

GitHub Pagesだけで動く、サーバー不要の画像文字CAPTCHAデモです。

## 特徴

- Node.js、API、データベース不要
- GitHub Pagesへそのまま配置可能
- CAPTCHA画像をブラウザ内で生成
- 「画像を更新」で毎回ランダムな6文字を生成
- 大文字・小文字を区別しない入力判定
- `I / O / 0 / 1` を候補から除外して誤読を軽減
- スマートフォン向けレスポンシブUI
- 画像はSVG Blobとして生成するため、外部画像ファイル不要

## GitHub Pagesでの利用

`index.html`、`style.css`、`script.js`を同じディレクトリに置くだけで動作します。Node.jsサーバーを起動する必要はありません。

## 重要な注意

この方式は完全にクライアント側で動くため、文字の正解もブラウザ内に存在します。そのため、**本番のセキュリティ対策としては不十分**です。フォームのいたずら防止やUIデモには使えますが、厳密なボット対策にはなりません。

本番で安全に使う場合は、次のいずれかを推奨します。

- Cloudflare Turnstileなどのサーバー検証付きサービス
- GitHub Pagesをフロントエンドにして、別ホストのAPIをバックエンドにする
- フォーム送信側でサーバー検証を行う

外部OCR APIを使って判定する設計は、APIキー漏洩・コスト増・認識誤りが発生するため採用していません。
